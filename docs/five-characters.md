## 使用方法

1. 将人物图接到 `reference_image`（角色1）、`reference_image_2`…`reference_image_5`。各接口接受一张图片，不能接图片批次。只需要连接场景中存在的角色。
2. 打开自由姿势编辑器，右上“添加”创建角色；左侧 C1–C5 单行显示已有角色，点击切换。每个按钮右上红色 × 删除，需在编辑器内确认；至少保留一个角色。编号固定，删除 C2 不会把 C3 改成 C2；添加时优先复用空编号。
3. 选中角色后，其模型呈蓝色并显示关节。导入单个 DUF 或点击3D图库只应用到当前角色。批量导入时，首个文件应用当前角色，其余文件新增角色；超出剩余槽位会提示。
4. 各角色可单独修改姿势、体型、比例、左右/上下/前后位置及大小。相机和输出图尺寸共用。“重新排列”会重新排列所有角色；仅在希望改变原来站位时使用。
5. 点击右上角“应用到节点”关闭编辑器，保存全部角色和合成人偶图。重新打开会恢复角色、姿势和当前选择。蓝色选中高亮不会进入人偶输出。

多人姿势图带数字编号，后端把这些编号与人物参考图绑定。编码顺序为合成人偶图、按角色编号排序的已用人物图，总计最多6张。空角色不占图像位置，提示词同步调整对应的 image 编号。模型生成时会被要求移除数字。

## 场景视角、位置与保存

- 右侧“整体调整”高亮时，大小、转身、左右/上下/前后滑块及三轴位移作用于所有角色；缩放同时缩放人物间距离，旋转绕共同中心执行。支持整体调整的撤销/重做；退出后恢复单角色编辑，点击 C1–C5 也会退出整体模式。
- “三轴位移”显示世界坐标红 X、绿 Y、蓝 Z 箭头，拖动只改变对应方向并同步右侧数值。关闭该按钮恢复关节编辑。Z 轴接近视线方向时，先转到斜侧视角更容易操作。
- 视角球上下方向已反转修正，鼠标灵敏度降为原来的三分之一；普通视角旋转、平移和 Shift 拖人物也已降低速度。

- 拖动预览区右上角 XYZ 球旋转场景，方向键可微调；Shift+拖动沿当前视图平面移动选中人物，右侧“前后”可精调深度。地面网格只辅助编辑，不进入输出。
- 浏览视角不会自行改变输出。点击“视角设为输出”把所有人物统一旋转、平移到固定输出相机坐标下，并返回正面查看结果；人物之间距离保持不变。输出裁切仍以人偶图尺寸和右下预览为准，宽高比不同的编辑区域不会完整等同于输出图。视角换算及整组落地会重建场景、清空角色的会话撤销记录，建议先保存场景。
- “保留 DUF 位置”默认开启，读取 figure 与 hip 的 translation，厘米转换到人偶的分米单位；导入和添加不再自动居中/排列。超过编辑范围会提示，不会静默截断位移。关闭此选项时仅替换姿势，保留当前角色位置与大小。
- “整组落地”按当前蒙皮模型的最低点计算共同的竖直位移，全体移动同一距离，保持彼此位置关系；不会把每个人分别拉到地面。
- 导入 DUF 自动保存原文件副本与解析动作。“保存角色”保存当前角色体型、比例、姿势与位置；“保存场景”保存全部角色及编号。两者均出现在3D图库中，点击角色动作应用到当前角色，点击场景需确认替换全部角色。保存格式是本插件 JSON，不是导出 DAZ `.duf`。
- 文件选择默认不限制格式，仍只接受 `.duf` 导入。网页不能指定 Windows 文件选择器的“超大图标”视图，需要在系统窗口中手动选择。

单位依据：[DAZ DSON 坐标/单位](https://docs.daz3d.com/public/dson_spec/format_description/units_coordinate_systems/start)、[MakeHuman 导出与单位说明](https://static.makehumancommunity.org/makehuman/docs/exports_and_file_formats.html)。文件选择器能力参见 [HTML file input](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/file)。

## 已知限制

验证记录见 [本地场景测试](scene-local-validation.md)。参考图编码测试覆盖5人及空槽位顺序，使用测试CLIP/VAE而非真实权重。

- 多人编辑与数据对应是确定性的；扩散生成中的身份一致性、遮挡和姿势还原仍取决于模型，属于实验性能力，尚未进行完整5人GPU生成质量验证。
- 多人图的数字可能偶尔出现在最终生成中，重叠角色可能发生身份混淆，建议避免头部和编号完全重叠。
- DUF 导入的是姿势，不是 DAZ 人物网格、服装、材质或变形器；不同代际骨架采用近似转移，原有脸部/眼睛等未映射限制仍存在。
- 已用 Carry Attacker/Victim 配套文件验证髋部旋转中心和 DSON 欧拉角顺序修正，不使用文件名判断或专用偏移。两文件没有骨架元数据，采用 G3/8 系列 bend/twist 命名；无明确代际时默认 G8/8.1 A 姿，明确 G3 则保留 T 姿。缺少源骨架时不能仅靠通道名称区分全部 G3/G8 预设；人物体型、角色缩放、外部资产和 ERC 仍可能导致手部接触等细节偏差。旧工作流保存的姿势不会自动改写，需重新导入 DUF 或从原始 DUF 图库重新应用。
- 添加、删除角色不自动移动其他角色。整体调整开启时“撑满”统一缩放和平移全部人物；关闭时只调整当前角色，可能破坏原配对比例/站位。
- 人物参考图保留在 ComfyUI 连接上，编辑器只显示预览；角色/场景动作库不打包人物参考图。
